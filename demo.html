Semantic cache

Ask something. Ask it again in different words. The cache decides whether it already has the answer — then tells you which layer decided and why. API docs

What to watch. The first question misses and gets generated. Reword it and the semantic layer serves the stored answer — look at the similarity score. It is often around 0.7–0.85, well below any threshold you could safely set. That is the point: a raw similarity number cannot make this call, so a second model reads both questions and decides. Ask about an API key instead of a password and it correctly refuses, despite scoring close.
